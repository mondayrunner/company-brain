# Knowledge index

The map. Every file in `knowledge/` gets one line here: what question it answers.

| File | Answers |
|---|---|
| `positioning.md` | Who are we for, who are we not for, why us? |
| `pricing.md` | What does it cost? |
| `compass.md` | What do we want, what do we not want? Read before giving advice. |
| `strategy.md` | Where are we heading, and what did we decide not to do? |
| `decisions.md` | What did we decide, when, and why? |

Add a line when you add a file. A file that is not in this index is hard to find and easy to forget.
