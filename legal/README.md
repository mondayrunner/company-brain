# Legal

This folder holds the documents you sign or send, each in one place. The same rule applies as for prices: the agent uses the version here, never one from an old email.

Put here, for example:

- `terms.md`: your terms and conditions, with the version date at the top.
- `contract-template.md`: the agreement you send to new customers.
- `data-processing.md`: your data processing agreement, if you handle customer data.
- `privacy.md`: your privacy statement.

Signed contracts belong with the customer, in `accounts/customers/<name>/`. This folder holds the templates and the current versions.

When a document changes, keep the old version with a `⚠️ SUPERSEDED` banner and a date. Customers who signed the old one are still bound by it.
